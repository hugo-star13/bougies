# Bougies

Petite web app pour iPad : formules de bougies artisanales et calcul des quantités (cire, parfums, additifs) selon la taille du contenant et le nombre de bougies.

- Fonctionne hors ligne une fois installée (Safari → Partager → « Sur l'écran d'accueil »).
- Les données restent sur l'appareil et ne sont jamais envoyées ici. Pensez à les sauvegarder depuis l'onglet « Sauvegarde ».
- Lecture des factures (onglet Stock) : le PDF de la facture est lu sur l'appareil, sans IA ni envoi sur internet. Les lignes repérées doivent être vérifiées et validées avant d'entrer dans le stock.
- HTML, CSS et JavaScript simples, sans outil de compilation. Hébergée sur GitHub Pages.
